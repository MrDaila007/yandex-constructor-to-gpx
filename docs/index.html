Яндекс Конструктор → GPX

Вставь публичную ссылку карты с um=constructor: или перетащи сохранённый HTML. Получишь трек и метки. Несколько линий — несколько файлов. Надёжный путь: открой карту в Яндексе и нажми букмарклет «GPX» (перетащи ссылку на панель закладок). Он выполняется целиком в закладке, без загрузки скриптов с github.io — иначе CSP Яндекса его блокирует.

Страница статическая, работает в браузере через CORS-прокси к Яндексу. Код: GitHub.
